# Сторінка-презентація уроку STEM-93

Кожен урок у `lessons/<lesson>/` **обов'язково** має `presentation.html`: одну сторінку, що прокручується, з анімацією. Слайди не потрібні: викладач назвав їх «нудними». Сторінку показують у класі учням ~10 класу, і вона лишається матеріалом уроку.

## Жорсткі правила (порушувались раніше — перевір перед публікацією)

1. **Перший рядок файлу — `<meta charset="utf-8">`**, далі `<meta name="viewport" …>` і `<title>`. Без charset кирилиця ламається, коли файл відкривають локально. Обгортка Artifact цього не рятує.
2. **Лише світла тема.** Темними можуть бути тільки справжні частини заліза: екран OLED, плата, корпус. Свідомо однотемна сторінка: усі кольори — токени в `:root`, у `body` явний фон, блоків dark-mode немає.
2a. **Ніжна сучасна палітра**: пастельні кольори (корал, вершкове масло, небесний, м'ята, лаванда), м'які тіні, текст на кольорових плашках — темний, а не білий. Яскраві «чисті» кольори урок 5 попросили зробити «ніжнішими».
2b. **Фото не кропимо**: банери показують повний кадр (урок 5: обрізало голову пам'ятника). Схему **малюємо в HTML/SVG** з клікабельними дротами. **Повна схема всіх уроків** (Uno, DFPlayer + динамік + 1 кОм, DS3231, OLED на I²C, кнопки A/B, реле + LED, шини 5V/GND, фільтр модулів) — у `lessons/lesson-05-box-it-up/presentation.html`, `<svg id="wireSvg">`: копіюй її в наступні уроки й дописуй нове залізо. Старі PNG з KiCad не вставляємо — вони застарілі.
3. **Українською.** Факти — **ті самі, що в README уроку** (піни, бібліотеки, цифри flash/RAM, рівень увімкнення реле тощо). Нічого не вигадувати про залізо: невідоме так і пишемо — «ще не уточнено».
4. **Статусу перевірки на сторінці немає** («Перевірено у Wokwi», «зібрано» тощо). Він живе в README і в чаті.
5. **Без брендів і логотипів.** Тема «Лего» → «цеглинки», «місто з цеглинок». Не пишемо назву бренду, не малюємо логотип.
6. **Ніколи не жартуємо** про хвилину мовчання, гімн, війну. Місто — через архітектуру, науку, парки, без болючих тем.
7. **Простота.** Перша версія уроку 3 (14 кліпів, довгі треди, код) була «забагато»: попросили «спростити». На зупинку — 1 головна думка + 1 інтерактив. Ікони й картинки замість тексту.
8. **Чесність прошивки й на сторінці:** «ГРАЄ / SOUND OK» лише після BUSY = LOW; реле — «CLICK?», а не «OK».

## Як обирати тему

Тему обирає викладач. Запропонуй 4–5 варіантів (місто або поп-культура). Для кожного опиши **метафору, що пояснює суть уроку**, а не лише прикрашає, і назви свою рекомендацію. Пройдені теми:

| Урок | Тема | Головна метафора | Що спрацювало |
| --- | --- | --- | --- |
| 1 | слайди Neo-Brutalism | — | **відкинуто**: «too crazy», слайди «нудні» |
| 2 | Stranger Things | справа секретної лабораторії: гірлянди, стіна з абеткою, досьє агентів | досьє учнів, симулятор-пульт |
| 3 | TikTok | вертикальна стрічка «кліпів» 9:16 + коментарі з теорією | симулятор меню за логікою прошивки; учні — «автори» з Trello-хендлами |
| 4 | Стамбул | Босфор = гальванічна розв'язка реле (берег 5 В / берег 220 В) | маршрут містом, калькулятор закону Ома, реле з клацанням, OLED-симулятор на справжніх байтах `icons.h`, кіт-провідник |
| 5 | Харків із цеглинок | Держпром (корпуси + містки) = модулі + дроти в коробці; дзеркальний струмінь = самоперевірка | фото міста з цеглинок, пластина RAM 2048 штирків, паспорт бага, гра «знайди погану пайку», колесо ідей, піксельна чернетка, білка-провідниця |

**Назву міста на сторінці не пишемо взагалі** — ні в тексті, ні у фактах, ні в прикладах коду, ні в іменах файлів (урок 5: викладач попросив прибрати «Харків»). Замість назви — «це місто», «Впізнали, яке це місто?»: учні люблять вгадувати. У README і пам'яті назву писати можна.

## Структура сторінки (перевірений каркас уроків 4–5)

Беріть за основу `lessons/lesson-05-box-it-up/presentation.html` (найновіший) або `lesson-04-wake-the-amp/presentation.html`, міняйте стиль, а не архітектуру.

1. **Коментар-задум** на початку `<style>`: метафора, палітра, «сторінка свідомо світла».
2. **Topbar** (sticky, `top: env(safe-area-inset-top)`): бренд «STEM-93 · Урок N · <тема>», маршрут-зупинки з номерами, кнопка «🔊 звук».
3. **Герой**: eyebrow «Урок N · Smart School Bell», великий заголовок-місія, лід із загадкою теми, блок «Місія», фото або SVG-сцена теми з легкою анімацією. За потреби — план дня (ширина блоку = хвилини).
4. **Зупинки** `section.stop` з `stop-head`: номер у стилі теми, «місце» (локація теми · що робимо), `h2`, підзаголовок-метафора, **клікабельна ілюстрація-орієнтир** (анімація + звук + бульбашка з правдивим фактом). Типовий порядок:
   - Команда і борги → виступи боргів → теорія з інтерактивом → **симулятор за логікою скетчу** → залізо / пайка / схема → челендж → **«Готово, якщо…» (DoD)**.
5. **Стрічка-роздільник** між зупинками (тюльпани, цеглинки…): клік → анімація, звук, іноді факт.
6. **Провідник** — фіксований персонаж у лівому нижньому куті (кіт Сіміт, білка Шпилька): поради по колу; кожен 5-й клік — «секрет».
7. **DoD** — чекбокси з `localStorage` (ключ `stem93-lN-<id>`, завжди в try/catch); усе відмічено → конфеті в стилі теми.
8. **Footer** — склад заліза одним рядком.

## Інтерактив, що «заходить»

- **Симулятор прошивки**: перенеси логіку зі `sketch.ino` (стан-машина, тексти Serial Monitor). OLED малюй на `<canvas width=128 height=64>` з `image-rendering: pixelated`; іконки — **ті самі байти, що в `icons.h`** (стовпці по 8 пікселів, молодший біт згори); текст — шрифт Press Start 2P 8px з бінаризацією пікселів. Дай «зламати» залізо галочками й подивитися, що покаже екран.
- Калькулятори з реальними числами (закон Ома, RAM 2048 Б), ігри «знайди помилку», генератор ідей, інструкція-гортанка.
- **Звуки синтезуй WebAudio** (без файлів): клацання реле, «клац» цеглинки, шипіння припою, плескіт. Звук лише після дії користувача, кнопка mute.
- Бульбашки `say(el, html)`, `burst()` частинок, `replay(el, cls)` для повторних анімацій — див. уроки 4–5.
- `prefers-reduced-motion` вимикає анімації.

## Фото, які дає викладач

- Кладуться в `lessons/<lesson>/img/`. Перейменуй у `city-N-<що>.png` (або інше нейтральне слово, без назви міста) латиницею; дублікати (однаковий md5) прибери.
- Оригінали спершу збережи поза репо (`D:\Arduino\_archive\…`).
- **Прибрати написи** (таблички тощо), лишивши все інше: OpenCV `inpaint` (Telea) за маскою тексту всередині заданого прямокутника (темний текст: `gray < median-22`; світлий: `gray > median+45` і низька насиченість), dilate, потім м'яке розмиття тільки всередині маски. Іконки поруч з текстом відновлюй з оригіналу. Перевіряй кожну табличку на кропі «до / після». Робочий скрипт — у venv у scratchpad (`pip install pillow numpy opencv-python-headless`).
- Для сторінки зроби JPG (~200 КБ, quality 82), у HTML — `img/….jpg`, `width/height`, `loading="lazy"` нижче першого екрана.

## Перевірка і публікація

1. `node` — синтаксична перевірка всіх `<script>`.
2. Один погляд: headless Chrome screenshot (`--window-size=1280,5200` і `400,3000`) обгорнутої копії. Видалити тимчасову копію.
3. Публікація через Artifact (`file_path` = `lessons/<lesson>/presentation.html`, `files` = `img/*.jpg`, `icon` — одне загальне слово). Посилання — викладачу; оновлювати тим самим `file_path`.
4. У README уроку — рядок «Сторінка-презентація для класу (тема — …): [presentation.html](presentation.html)»; у `lessons/README.md` і `dev/lessons.md` — тема й посилання.
5. Записати тему, метафору, нікнейми й URL артефакту в пам'ять (feedback-presentation-style).
