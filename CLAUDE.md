# Додатково для Claude

## Кожен урок — з тематичною презентацією

- Кожна папка уроку `lessons/<lesson>/` **обов'язково** містить `presentation.html`: тематичну анімовану сторінку для класу (місто / поп-культура). Тему обирає викладач. Роби за скілом [`stem93-lesson-page`](.claude/skills/stem93-lesson-page/SKILL.md) або доручи агенту `lesson-presenter`.
- З уроку 5 урок = **README + скетч + презентація**. Wokwi і KiCad не робимо, поки викладач не попросить (KiCad заархівовано в `D:\Arduino\_archive\stem-93-kicad`).

## HTML: завжди UTF-8

- **Перший рядок кожного HTML-файлу — `<meta charset="utf-8">`**, перед `<title>` і будь-яким кириличним текстом. Обгортка Artifact додає charset сама, але локально відкритий файл без нього показує «кракозябри». Перед публікацією перевір: `head -c 300 файл | grep -i 'charset="utf-8"'`.
- Файли з кирилицею зберігай як UTF-8 (у PowerShell — `-Encoding utf8`).
