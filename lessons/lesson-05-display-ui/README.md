# Урок 5 — Display / User Interface 🖥️

> **Mission:** пристрій повідомляє користувачу, що відбувається.

## Обладнання

| Компонент | Статус |
| --- | --- |
| Дисплей | **модель не визначена** (OLED/LCD, розмір, інтерфейс) — обрати з урахуванням вільних пінів Uno |

## Приклади екранів

Очікування:

```text
SCHOOL SYSTEM

10:14

NEXT:
10:15 MUSIC
```

Під час відтворення:

```text
▶ PLAYING

Track 001
```

Після завершення:

```text
READY

Next:
10:30
```

## Що вирішує команда (Product + UX)

- що показувати;
- які стани потрібні (READY, PLAYING, ERROR…);
- які помилки показувати (немає SD, немає часу, трек не запустився).

## Definition of Done

- [ ] Дисплей показує поточний час і наступну подію.
- [ ] Показує PLAYING лише після підтвердження відтворення.
- [ ] Показує помилки зрозумілими словами.
