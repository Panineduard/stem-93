We take the device from lesson 2 and add:

  • An OLED display: the current time and the schedule, shown with icons instead of words.
  • Two buttons: change the schedule without a laptop.

A+B → current time → A+B → minute of silence → A+B → quote of the day → A+B → save.

The time is written to the DS3231 clock, the schedule to EEPROM. Both survive a power-off.

Display and memory

Arduino Uno RAM = 2048 B

A 128×64 screen = 1024 bytes. That is half of the Uno's memory.

Comments 1
A
Anna @anettt_ticreator
  • OLED SSD1306, 0.96", 128×64 pixels. Every pixel lights up by itself.
  • The Adafruit library keeps a copy of the screen in memory: 1024 bytes. The Uno can't spare them.
  • So we use U8x8: it writes characters straight to the screen, with no copy.
  • U8x8 has no Cyrillic, so the screen uses icons instead of words: a candle, a flag, a speech bubble. Each one is drawn with "#" and "." in icons.h.

The clock and the display share the same two wires and don't get in each other's way. #i2c

original sound — START · 0x3C · ACK ·
Comments 1
D
Denys @deny_19creator
  • Every device on the bus has its own address: the clock is 0x68, the display is 0x3C.
  • The Arduino calls an address, and only that device answers.
  • If the display does not answer, the Serial Monitor shows an error and the bell keeps working.

One press, several "clicks". Look at the red line. #buttons

original sound — click-click-click ·
Comments 1
93
@stem93creator
  • The button connects the pin to GND. Pressed = LOW, released = HIGH.
  • The contacts "bounce" for a few milliseconds. So a new value is accepted only after it has held for 30 ms.
  • "+1" fires when the button is released. That gives you time to press the second button for A+B.
